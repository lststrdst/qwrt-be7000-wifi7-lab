Быстрая настройка VPN

WireGuard · AmneziaWG · VLESS / Xray · Mieru. Создание приватных конфигураций непосредственно на роутере. Существующие подключения не перезаписываются.

Любой профиль включается только после новой предварительной проверки и явного подтверждения. WG/AWG используют отдельные интерфейсы и собственные правила NETSCOPE; VLESS/Mieru запускают SOCKS только на loopback. Мастер не меняет UCI, DNS, default route и существующие VPN.

Проверяю необходимые компоненты…

Быстрая настройка

Перед созданием ключей роутер проверяет активные UDP-порты.

Не должна пересекаться с домашней сетью и офисными маршрутами.

Домашняя подсеть определяется на этом роутере и не копируется из сети разработчика.

Секретное поле: данные не сохраняются в браузере и не отправляются в аналитику. Требуется TLS или Reality. Ссылки подписок и полные конфигурации Xray пока не принимаются.

Сервера ещё нет? Оставьте адрес, имя пользователя и пароль пустыми, чтобы скачать явно помеченный шаблон. Для рабочего подключения нужен существующий сервер Mieru.
