Что изменится при включении и как работает откат

Любой профиль включается только после новой предварительной проверки и явного подтверждения. WG/AWG используют отдельные интерфейсы; VLESS/Mieru слушают только loopback; HY2 поднимает изолированный TUN без маршрутов. Неподтверждённый запуск откатывается watchdog. Голосовой маршрут включается отдельно.

      Адреса и параметры маршрута

      Только целевой UDP Telegram и Discord идёт через HY2, активный Mieru UDP используется как резерв. После двух сбоев HY2 маршрут переключается на Mieru и возвращается после восстановления. Если оба канала недоступны, правило снимается (fail-open). Steam, Dota, остальной UDP, default route и L2TP не меняются.

      Для стабильной маршрутизации Telegram отключите P2P звонков: Настройки → Конфиденциальность → Звонки → Peer-to-Peer → Никто.

      Как работает восстановление

      Watchdog следит за PPP и офисными маршрутами, восстанавливает MTU 1400 / MSS 1360. После трёх ошибок вызывает приватный reconnect-helper. Сеть и firewall целиком не перезапускаются.
