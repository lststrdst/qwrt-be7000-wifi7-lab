Быстрая настройка VPN

WireGuard · AmneziaWG · VLESS / Xray · Mieru · Hysteria 2. Создание приватных конфигураций непосредственно на роутере. Существующие подключения не перезаписываются.

Любой профиль включается только после новой предварительной проверки и явного подтверждения. WG/AWG используют отдельные интерфейсы; VLESS/Mieru слушают только loopback; HY2 поднимает изолированный TUN без маршрутов. Голосовой маршрут включается отдельной кнопкой и не меняет системный default route, L2TP или правила игр.

Быстрая настройка

Перед созданием ключей роутер проверяет активные UDP-порты.

Не должна пересекаться с домашней сетью и офисными маршрутами.

Домашняя подсеть определяется на этом роутере и не копируется из сети разработчика.

Вставьте один экспортированный HY2-узел или один Hysteria outbound JSON из Happ, но не ссылку на подписку. Профиль создаёт локальный SOCKS5/UDP и изолированный nshy2, но без отдельного policy rule сам не перенаправляет Telegram, Discord или игры.

Секретное поле очищается после подготовки. Для Happ JSON принимается только Hysteria 2 + TLS + ALPN h3; полная подписка отклоняется.

Секретное поле: данные не сохраняются в браузере и не отправляются в аналитику. Требуется TLS или Reality. Ссылки подписок и полные конфигурации Xray пока не принимаются.

Вставьте одну экспортированную ссылку Mieru — роутер разберёт её штатным runtime и сохранит только приватный профиль на USB. Либо заполните поля вручную. Для голосового резерва ссылка должна содержать UDP binding.

Секретное поле очищается после подготовки. Ссылка не попадает в plan.json, браузерное хранилище или публичный репозиторий.

      Звонки Telegram и Discord: HY2 + Mieru reserve

      Роутер направляет только целевой Telegram/Discord voice UDP через основной HY2. Активный Mieru с UDP и TUN adapter держатся прогретым резервом: после двух сбоев HY2 маршрут переключается на Mieru, а после восстановления возвращается обратно. Если недоступны оба канала, правило снимается fail-open. Steam, Dota, остальной UDP, системный default route и L2TP не меняются.
