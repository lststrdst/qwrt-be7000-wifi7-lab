# NETSCOPE firmware

Я развиваю NETSCOPE как собственную сборку для Xiaomi BE7000 на базе QWRT.
В этом каталоге постепенно собираю компоненты будущего образа. Лаборатория
Wi-Fi 7 остаётся отдельным направлением: интерфейс NETSCOPE не означает,
что закрытый драйвер уже умеет рабочий MLO в этой загрузочной цепочке.

**Готового образа для прошивки здесь пока нет.** Не переименовываю бэкап
своего роутера в публичную прошивку и не включаю чужие ART, ключи или пароли.
Исходники точной базы QWRT R26.02.02 / QSDK 12.5 либо совместимый закреплённый
ImageBuilder пока не получены. Наличие другого OpenWrt-порта не делает его
совместимым с текущей разметкой и закрытыми драйверами.

## Что уже есть

- `packages/luci-app-netscope-setup` — исходник мастера **VPN Quick setup**.
  WG/AWG создают уникальную пару серверного и клиентского конфигов;
  VLESS проверяется установленным Xray; Mieru пока готовит клиентский шаблон.
  AWG/VLESS/Mieru остаются prepare-only. Для обычного WireGuard добавлен
  отдельный транзакционный runtime: свежий preflight, явное подтверждение,
  собственные chains и watchdog rollback. Он не меняет UCI/default route и
  не перезапускает network/firewall. Мастер
  проверяет занятые UDP-порты и пересечение новой подсети с живыми маршрутами,
  затем сохраняет отдельный обезличенный план будущей активации. Сохранённые
  черновики видны в вебке; для них доступны повторный read-only preflight и
  подтверждаемое удаление только выбранного неактивного каталога. После reboot
  профиль остаётся выключенным: скрытого autostart нет.
- [Описание мастера](../docs/VPN-QUICK-SETUP.md), включая ограничения и хранение секретов.
- [SSH через XMiR-Patcher](../docs/INSTALL-SSH-XMIR.md) — отдельный этап доступа,
  не универсальный способ прошивки.
- [Условия выпуска образа](RELEASE-CHECKLIST.md) и профиль целевой базы.

Исходники мастера проверены на реальном QWRT R26.2.2; создание `.ipk` через
совместимый SDK и включение пакета в полный образ ещё не проверены.
Пакет рассчитан на старый Lua LuCI. Совместимость с новым JavaScript LuCI
и другими сборками OpenWrt не заявляю без тестирования.

## Сборка компонента, когда получен совместимый SDK

Поместить `packages/luci-app-netscope-setup` в `package/` SDK. Через
`make menuconfig` выбрать LuCI → Applications → пакет, затем выполнить:

```sh
make package/luci-app-netscope-setup/compile V=s
```

Это команда сборки **пакета**, не готового firmware image. Проверять пакет
сначала в `opkg --offline-root` и на тестовой системе. Не применять
`--force-depends` к работающему роутеру. Зависимости обычного WireGuard указаны
явно; AWG, Xray и Mieru runtime в пакет не входят. Готовых пользовательских
конфигов в репозитории нет.

Ресурсы QWRT, LuCI, Xiaomi/Qualcomm и библиотек сохраняют собственные лицензии
и авторство. Моя MIT-лицензия относится к моему коду, а не передаёт права
на распространение закрытых компонентов базовой прошивки.
