# Правовой статус

Это независимый проект по исследованию совместимости и безопасному
тестированию. Он не является официальным проектом QWRT, Xiaomi, Qualcomm или
OpenWrt и не поддерживается этими организациями.

Лицензия MIT относится только к оригинальному коду и документации этого
репозитория. Образы QWRT и Xiaomi, прошивки Qualcomm, board data, калибровка
конкретного устройства и извлечённые vendor-скрипты здесь не публикуются и
остаются под своими лицензиями.

Название QWRT используется только для обозначения проверяемой среды. На момент
создания проекта публичный репозиторий исходников, соответствующий бинарной
сборке QWRT R26.02.02 для Xiaomi BE7000, найден не был. Поэтому этот проект не
выдаётся за форк её исходников.
