# NETSCOPE selective VLESS/Reality

На базе QWRT обычный WAN остаётся маршрутом по умолчанию, а в Xray отправляются только адреса,
попавшие в `ipset`. DNS выбранных доменов проходит через защищённый resolver и
одновременно заполняет тот же `ipset`.

`config.example.json` содержит локальный SOCKS и два transparent-inbound: TCP
`REDIRECT` и UDP `TPROXY`. На некоторых старых QSDK TCP TPROXY не передаёт
соединение Xray, поэтому TCP REDIRECT бывает совместимее.

Перед применением необходимо заменить все `REPLACE_*`, проверить Xray через
локальный SOCKS и только затем добавлять правила перехвата. Готовый `vless` URI
публиковать нельзя: он содержит доступ к серверу.

Реальный генератор списков должен применять обновление атомарно, сохранять
последнюю рабочую копию и отбрасывать подозрительно пустой результат.
