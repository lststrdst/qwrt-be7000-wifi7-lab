# Обезличенные VPN-примеры NETSCOPE

Это справочные каркасы для будущих runtime NETSCOPE. Все адреса, ключи, UUID, логины и
домены являются заглушками. Файлы с суффиксом `.example` нельзя копировать на
роутер без проверки и замены значений `REPLACE_*`.

- [`l2tp/`](l2tp/) — клиент L2TP/IPsec с PAP и fail-closed маршрутами;
- [`vless/`](vless/) — минимальный Xray VLESS/Reality и связка с dnsmasq/ipset;
- [`amneziawg/`](amneziawg/) — userspace-шаблоны сервера и клиента AmneziaWG.

Правила, которых я придерживаюсь:

1. WAN остаётся маршрутом по умолчанию.
2. Приватные назначения перечисляются явно.
3. При падении туннеля остаётся blackhole, а не утечка трафика в WAN.
4. Секреты создаются на целевом устройстве с `umask 077`.
5. Тест начинается с одного адреса и только потом расширяется до подсети.
