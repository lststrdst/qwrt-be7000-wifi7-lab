# NETSCOPE AmneziaWG remote access

Этот пример показывает отдельный userspace-интерфейс AmneziaWG для удалённого
доступа домой. Я не заменяю им обычный WAN и не открываю UDP 7/9 для WOL.

```text
телефон 10.77.0.2 -> awg_remote 10.77.0.1 -> домашняя LAN
                                             -> выбранные office/VLESS routes
```

`client-lan.conf.example` даёт только доступ к дому. В
`client-full-tunnel.conf.example` весь трафик телефона входит в домашний
роутер, после чего существующие policy-правила могут отправить выбранные
назначения в VLESS или офисный туннель.

Параметры `Jc`, `Jmin`, `Jmax`, `S1`, `S2`, `H1`–`H4` должны совпадать на
клиенте и сервере. Числа здесь иллюстративны. Секреты генерируются локально;
серверный конфиг и клиентский QR хранятся с правами `0600` и не попадают в Git.
