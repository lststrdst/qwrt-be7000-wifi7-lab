# NETSCOPE 1.0 beta 1 — Easy Setup

Первый номерной beta-выпуск NETSCOPE от lststrdst для Xiaomi BE7000 (RC06),
**based on QWRT R26.2.2 / QSDK 12.5**. Сохраняю авторство и лицензии upstream.

## Что добавил

- Easy Setup: вставка VLESS/HY2/Mieru, импорт файла, списка/base64 и
  поддерживаемой JSON-подписки; явный выбор узла.
- Защищённая одноразовая загрузка HTTPS-подписки с роутера: проверка TLS,
  блокировка непубличных адресов, DNS pinning, лимиты, без redirect.
- Понятный переход: импорт → выбор → приватный черновик → preflight →
  подтверждение. Сеть не меняется от одной вставки ссылки.
- Импорт в визуальном стиле NETSCOPE; никаких чужих routing/DNS/inbound
  из приложения. Секреты не входят в публичный пакет.
- Проверка состава архива, SHA-256 и воспроизводимости сборки; лицензия и
  инструкция включены в архив. Следующие beta-релизы публикуются по тегам.

## Что именно скачивать

`netscope-xiaomi-be7000-qwrt-r26.2.2-overlay-1.0.0-beta.1.tar.gz` и соседний
`.sha256` — **установочный overlay, не образ прошивки**.

Установка только поверх уже работающей точной базы QWRT R26.2.2 с USB
`/mnt/sda1`. Проверяется модель/target/revision; создаётся резервная копия.
Перед установкой нужно выключить Capture и активные профили NETSCOPE.
Установщик не пишет NAND/UBI и не перезапускает сеть целиком.

**Не загружать этот архив в sysupgrade/обновление прошивки LuCI или Xiaomi.**
Для стоковой прошивки это не установочный файл. GitHub Source code ZIP/TAR
тоже не является factory/sysupgrade image.

## Ограничения beta

Полный factory/sysupgrade пока не выпускаю: не закреплены совместимые
исходники/toolchain, права на распространение vendor-компонентов, NAND/UBI
и аппаратные recovery-тесты. Переименование overlay в `.bin` этого не решает.

VLESS/Mieru запускаются как отдельные клиенты, не маршрутизируют весь LAN
автоматически. HY2 voice policy включается отдельно. Полный LAN/VPN/офис
мастер, clean-install матрица всех протоколов и аппаратные отказные тесты
ещё в работе. MLO остаётся render-only лабораторией без live apply.

Это prerelease для осознанного тестирования, не заявление о production-ready
прошивке. Компьютерные модели и CI не заменяют аппаратный recovery.
