# SSH через XMiR-Patcher и будущая установка NETSCOPE

Это инструкция подготовки доступа к **своему Xiaomi BE7000 RC06**. Готового
образа NETSCOPE пока нет: после получения SSH прошивать из этого репозитория
нечего. Я не объединяю разблокировку SSH и запись NAND в одну кнопку.

## Если уже установлен QWRT

Повторно запускать exploit для stock обычно не требуется: использовать уже
работающий SSH и пароль администратора. Сначала сделать backup конфигурации
и сохранить его вне роутера. Не заливать backup чужого устройства и не
восстанавливать заводскую разметку ради установки веб-пакета.

## Если ещё заводская Xiaomi

1. Записать точную модель, версию stock и текущий LAN-адрес. Совместимость
   exploit зависит от версии; эта инструкция не обещает работу с любой stock.
2. Подключить ПК кабелем. Обеспечить стабильное питание и сохранить независимый
   интернет для документации. В браузере проверить доступ к штатной вебке.
3. Скачать [XMiR-Patcher из исходного репозитория](https://github.com/openwrt-xiaomi/xmir-patcher).
   Сохранить использованный commit/архив и SHA-256: ветка main меняется.
   Windows: `run.bat`; Linux/macOS: Python 3.8+, OpenSSL, `run.sh` — согласно
   [README автора](https://github.com/openwrt-xiaomi/xmir-patcher/blob/main/README.md).
4. В главном меню указать IP роутера (пункт 1), подключиться (2), прочитать
   сведения устройства (3), сделать полный backup (4). Проверить, что backup
   действительно считан, его размеры/хеши и копия вне компьютера сохранены.
5. Отдельно выбрать постоянный SSH (6), только если средство подтверждает
   поддержку вашей модели/версии. После этого проверить новый SSH-вход,
   задать собственный root-пароль и не открывать SSH в WAN.

Номера сверены с [menu.py upstream](https://github.com/openwrt-xiaomi/xmir-patcher/blob/main/menu.py)
5 сентября 2026 года; при отличиях ориентироваться на подписи и исходники
используемой версии. Если SSH/backup не получились, остановиться, а не
пробовать случайные пункты установки загрузчика.

**Не выбирать установку firmware (7), Breed или смену boot address по этой
инструкции.** Для этого необходим конкретный проверенный образ и план
перехода между разметками. Кабель не заменяет UART при повреждённой загрузке.

## Что сохранить приватно

Полный backup разделов именно своего устройства, ART/caldata, таблицу MTD,
boot metadata, конфигурацию сети и VPN. Разные типы backup не заменяют друг
друга: LuCI/sysupgrade configuration backup не является полным NAND backup.
Проверить чтение архива, контрольные суммы и способ восстановления заранее.
Не добавлять эти файлы, пароль, SSH-ключи и subscription URLs в GitHub.

## Когда появится образ

Инструкция конкретного релиза должна отдельно описывать stock → NETSCOPE
и обновление NETSCOPE → NETSCOPE, содержать размеры/хеши, требования к разметке
и проверенный recovery. Пока [release gates](../firmware/RELEASE-CHECKLIST.md)
не закрыты, универсальной команды прошивки здесь намеренно нет.

XMiR-Patcher — отдельный проект его авторов, не моя разработка. QWRT, LuCI
и Xiaomi/Qualcomm сохраняют исходное авторство и собственные лицензии.
