# Easy Setup — добавить VPN без ручной сборки JSON

Я добавил в NETSCOPE импорт узла из ссылки, файла и поддерживаемой подписки.
Мастер не заменяет конфигурацию роутера конфигурацией стороннего приложения.

[Редактируемый макет в Figma](https://www.figma.com/design/rpSpM5mXmSmBqVEum5w3FH?node-id=17-2)
с демонстрационными данными. Стиль мастера изолирован в `setup.css`;
используются штатные HTML/CSS/JavaScript и Lua/LuCI, без React/Tailwind на роутере.

1. Откройте **Быстрая настройка VPN → Подключение к VPN** (или «Звонки»).
2. Вставьте ссылку и нажмите **Загрузить и разобрать** либо выберите файл.
3. Выберите узел из списка → **Выбрать узел**.
4. Нажмите **Подготовить конфигурацию**. На USB появится приватный черновик;
   сеть пока не изменится. При ошибке компонента откройте раздел компонентов.
5. В «Моих подключениях» нажмите **Проверить и подключить**. Прочитайте план,
   затем явно подтвердите включение. Неподтверждённый запуск откатывается.

## Что поддерживается в 1.0 beta 1

- VLESS URI: TLS/Reality; TCP/RAW, WebSocket, gRPC, базовый XHTTP; UUID,
  `encryption=none`. Vision — TCP/RAW. Расширенные параметры, которые мастер
  не умеет переносить, вызывают ошибку, а не теряются молча. Для них используйте
  исходящий Xray JSON. Основа разбора — [спецификация Xray](https://github.com/XTLS/Xray-core/discussions/716).
- Одиночные ссылки HY2/Hysteria 2 и Mieru/Mierus. Mieru проверяет свою ссылку
  штатным runtime; для резерва звонков нужен UDP-профиль.
- Список ссылок построчно, его base64-представление, массив Xray-конфигов
  (включая JSON-экспорт Happ), один конфиг с `outbounds` или объект `configs`.
- HTTPS-подписка и обёртка Happ `add`. Только порт 443, публичный IPv4,
  HTTP 200 без перенаправлений. Сертификат сервера должен быть доверенным.
- Не более 64 КБ, 100 узлов, 12 КБ на выбранный узел. IPv6-only сервер
  подписки, YAML/Clash, VMess/Trojan и произвольные схемы не поддерживаются.

Файл и текст разбираются в браузере. HTTPS-загрузка — отдельный авторизованный
POST с CSRF-защитой: DNS проверяется, публичный адрес закрепляется на время
TLS-запроса, перенаправления и унаследованный HTTP-прокси отключены. URL с
токеном не передаётся в аргументах процесса curl и не выводится в ошибки.
Временный запрос хранится в закрытом RAM-каталоге, удаляется после запроса;
при аварийном завершении процесса остаток исчезнет после перезагрузки.
Тело ответа ограничено памятью и не пишется на flash/USB. Подписка не
обновляется фоново и не сохраняется целиком. Поля очищаются после подготовки
и ухода со страницы; это не гарантия криптографического стирания памяти браузера.

## Важно: профиль — не маршрут всей локалки

| Сценарий | После явного включения |
|---|---|
| Доступ домой, WG/AWG | Собственный интерфейс, ключи и ограниченные правила доступа; внешний адрес/DDNS и доступность входящего UDP нужны отдельно |
| VLESS/Mieru | Отдельный локальный клиент SOCKS; домашняя сеть автоматически через него не направляется |
| HY2 | Изолированный TUN; голосовой маршрут Telegram/Discord включается отдельной кнопкой |

DNS, inbound и правила маршрутизации из подписки не импортируются. Связки с
`proxySettings`/`sockopt` требуют ручной настройки. Для полноценного мастера
«эти устройства/сайты — через VPN, офис — через L2TP» ещё нужен безопасный
редактор policy routing с проверкой пересечений и откатом. В beta 1 он **не готов**.

Не публикуйте подписки, UUID, пароли, ключи и снимки заполненных полей.

## Доступ домой и голосовой канал

Для WG/AWG предлагаемые порт, подсеть и домашние маршруты определяются на
вашем роутере. Они находятся в «Параметрах домашней сети». Проверки конфликтов
повторяются перед запуском; мастер не меняет адрес LAN и не перезапускает Wi-Fi.

Голосовая карточка показывает основной HY2 или резерв Mieru, готовность
резерва и контрольные UDP-пробы, **не задержку разговора**. Видна подходящая
кнопка запуска/остановки; автозапуск — отдельное действие. Обновление адресов
Telegram и диагностика находятся в подробностях. Включение voice policy
может перезапустить DNS, как и в предыдущей реализации.

## Стенд и границы проверок

```sh
node tools/preview-quick-setup.cjs
```

Локальный стенд на порту 4187 поддерживает `scenario=off`, `reserve`, `empty`,
`missing`, `error`: ответы искусственные, команды не доходят до роутера.
Для read-only галереи есть `node tools/preview-gallery.cjs`, порт 4190.
В обоих стендах используются только вымышленные конфигурации.

Предыдущая проверка на авторизованном Chrome охватила Quick Setup, Систему,
Администрирование, Интерфейсы и Wi-Fi без применения настроек; на 390 px
проверены пять протоколов и переносы кнопок. Read-only аудит нашёл 213 узлов
LuCI без отсутствующих целей и дублирующихся соседних названий. Это не
проверка всех изменяющих систему кнопок. Активации всех протоколов с внешними
серверами и восстановление после reboot требуют отдельного стенда.
