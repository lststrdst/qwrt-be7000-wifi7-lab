# История изменений NETSCOPE

## 0.7.0-dev — 2026-09-06

- Quick Setup умеет безопасно установить официальный Mieru v3.36.1 ARM64 на USB:
  закреплены SHA-256 архива и бинарника, установка не запускает VPN и не меняет сеть;
- запуск Mieru теперь проходит сквозную SOCKS5 UDP/STUN-пробу и откатывается,
  если удалённый транспорт фактически не передаёт UDP;
- голосовой маршрут HY2 получил безопасный opt-in автозапуск после загрузки:
  сервис не подменяет другой активный профиль, поднимает только подтверждённый
  приватный draft и при любой ошибке сначала снимает свой policy route;
- в NETSCOPE добавлена локальная телеметрия голоса: текущие Telegram/Discord
  endpoint, выбранный маршрут, задержка контрольной UDP/STUN-пробы, jitter,
  потери и ограниченная история на USB без payload звонков;
- добавлен отдельный opt-in watchdog существующего офисного L2TP: проверка PPP,
  обязательных маршрутов, MTU 1400 и собственного MSS 1360, три ошибки до
  scoped reconnect и отсутствие глобального `network/firewall restart`;
- обновлены русские экраны NETSCOPE и VPN Quick setup, release-метаданные,
  мобильные сетки и проверки на дублирующиеся HTML id;
- Mieru на USB теперь корректно обнаруживается транзакционным диспетчером;
  резерв голосового маршрута остаётся отдельным этапом до установки runtime,
  TUN-адаптера и успешной UDP-пробы.

## 0.6.0-dev — 2026-09-06

- в VPN Quick Setup добавлена приватная заготовка Hysteria 2 с SOCKS5/UDP
  на `127.0.0.1:2083`, изолированным TUN `nshy2`, отдельным runtime-state и
  watchdog; сам TUN не получает default route и ничего не перехватывает;
- добавлена явная установка официального ARM64 runtime v2.11.0 на USB с
  закреплённым SHA-256, без запуска процесса или изменения сети;
- HY2 принимает один экспортированный узел, очищает секретное поле в браузере
  и блокирует `insecure` без закреплённого `pinSHA256`;
- HY2 также принимает один native Hysteria 2 outbound JSON из Happ, не сохраняя
  полную подписку и не перенося неподдерживаемые proxy/sockopt-поля;
- добавлен отдельный voice route только для UDP к проверенным Telegram relay CIDR,
  выделенной сети Discord/i3D, текущему Cloudflare Edge voice-префиксу и
  динамическим `*.discord.media`/`*.discord.gg`: собственные ipset, метка `0x2`,
  таблица 101 → `nshy2`, настоящая UDP-проба и fail-open watchdog без захвата
  Steam/Dota/L2TP/VLESS; отказались от `xt_TPROXY`, не доставлявшего UDP в
  userspace на проверенной QSDK-сборке;
- зафиксировано ограничение маршрутизатора: после включения Happ он видит один
  шифрованный туннель и не может разделить Telegram/Discord и игру по процессам;
  Telegram P2P также использует произвольный IP собеседника.

## 0.5.0 — 2026-09-06

- опубликованы русская тема NETSCOPE, Traffic/Devices и управляемые USB PCAP-сессии;
- добавлен installable overlay для точной QWRT R26.2.2 с manifest, SHA-256,
  backup и rollback без записи firmware-разделов;
- Quick Setup получил отдельные транзакционные runtimes для WG, AWG,
  VLESS/Xray и Mieru; недостающие бинарники блокируют активацию;
- в администрирование добавлена явная кнопка сохранения пароля через штатный
  POST LuCI без отдельного хранения значения;
- удалён устаревший listener, привязанный к фиксированному тестовому клиенту;
- добавлены исходники контроллера HTTPS lab и fail-safe cleanup; Docker/image/CA
  не запускаются и не создаются автоматически.

## 0.3.0 — 2026-09-05

- проект, Python-пакет, OpenWrt helper, CI и дерево каталогов переименованы в
  единую схему NETSCOPE;
- README разделяет опубликованный код, локальные прототипы, модели и планы;
- добавлены архитектура и roadmap будущей прошивки;
- уточнено ограничение стоковой Xiaomi: MLO из двух 5‑ГГц линков нельзя
  штатно совместить с отдельным 2,4‑ГГц IoT SSID;
- репозиторий оформлен как проект прошивки NETSCOPE для Xiaomi BE7000 на базе QWRT;
- добавлены отдельные документы по IoT-сегменту и Wi-Fi 7/MLO;
- добавлена модель supervised MLO trial без UART: только RAM, без live apply,
  UCI/autostart/bootenv/MTD/ART и с явными исходами для rollback, reboot и kernel hang;
- добавлены негативные тесты всех recovery gates и запрет постоянных изменений;
- подготовлен экран Wi-Fi 7 Lab в Figma с заблокированным live apply;
- добавлены обезличенные шаблоны L2TP/IPsec, VLESS/Reality и AmneziaWG;
- добавлена локальная и CI-проверка публичного дерева на секреты;
- связанные материалы объединены ссылками из русского и английского README.

## 0.2.0 — 2026-09-04

- опубликован read-only монитор соединений IoT;
- добавлена инструкция восстановления для администраторов;
- расширены проверки лаборатории Wi-Fi 7/MLO.
